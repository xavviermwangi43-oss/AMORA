# AMORA Android APK

This project packages the existing AMORA Netlify web app as an Android APK.

App URL: https://gentle-queijadas-da6b74.netlify.app/
Package ID: com.amora.app
Version: 1.0 (code 1)

## Build for free with GitHub
1. Upload all files in this folder to a GitHub repository.
2. Open the repository's Actions tab.
3. Run **Build AMORA APK** (or push to main).
4. Open the completed workflow run.
5. Download the **AMORA-debug-apk** artifact.
6. Extract it and install `app-debug.apk` on Android.

The APK loads the live Netlify app, so website updates appear in the APK without rebuilding it.
